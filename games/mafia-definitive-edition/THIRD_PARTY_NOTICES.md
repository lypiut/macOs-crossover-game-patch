# Third-party notices

The shader assets bundled for this patch are adapted from the
[RenoDX](https://github.com/clshortfuse/renodx) Mafia: Definitive Edition module
at revision `9b212edad4dde9bca2b823b1e045b712b1a8d854`.

Local changes replace RenoDX's runtime `b13` setting reads with fixed literal
defaults, select Mafia's vanilla film-grain branch, and embed the proxy shaders
in a game-local executable section. No RenoDX, ReShade, or game binary is
included.
